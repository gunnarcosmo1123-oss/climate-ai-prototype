# 🌍 ClimateOS · 气候智脑 — AI for Climate 高保真交互原型

> **一句话定位**:AI 驱动的"地球气候操作系统"——面向政府决策者、城市规划师与公众,把海量气候数据变成**看得懂、可推演、能行动**的决策智能。

适用于:气候大会路演、政策汇报、AI 应用大赛展示、课程大作业。**中英文双语,一键切换。**

## 📅 数据覆盖:2025–2026 已接入

2025 年为报告值近似(温升 +1.60°C、CO₂ 427.6 ppm、风光装机 17 亿千瓦),2026 年为全年预估值(温升 +1.52°C、CO₂ 430.2 ppm、风光 20.5 亿千瓦),所有 AI 预测起点顺延至 2026 年。

## ⭐ 演示亮点

1. **政策推演器(核心交互)**:拖动「碳价 / 风光投资 / 电气化 / 能效」滑块,AI 实时重算排放路径与达峰年份。归零 → 2030 年达峰、2060 排放 6.4 Gt;拉满 → 净负排放。
2. **世界地图热力大屏**:4 项指标热力图 + 实时时钟 + 事件播报 + 预测中心,全屏模式一键进入(⛶),适合开场大屏演示。
3. **AI 预测中心**:1.5°C 突破推演(距长期突破仅 1 年)、北极海冰 2050、2100 海平面四情景、气候保险损失、风光/储能/绿氢、高温日数、作物减产——8 类长期预测。
4. **数据联动的 AI 助手**:问"当前政策组合何时碳达峰?",AI 直接读取推演器当前滑块状态作答,并标注数据来源。
5. **详细应对措施**:每座城市按风险画像生成 3 类 × 3 措施的行动方案,点击展开实施路径(分年步骤)、资金来源与核心指标。

## 🔧 技术说明

- **纯前端 HTML/CSS/JS,零依赖**,任何电脑离线可用
- **世界地图**:`world-atlas@2 countries-110m`(公共领域数据)经构建脚本离线嵌入,含 177 国真实边界
- **AI 能力**(原型实现,非在线大模型):
  - 趋势拟合:最小二乘线性回归(温度、CO₂、海平面、极端天气、北极海冰…)
  - 政策推演:排放增速 ρ(t) = A − B·(t−2020) − C·(t−2020)² 参数化模型 + CCUS 捕集
  - 规则引擎:知识库问答(双语)、风险画像 → 措施生成、洞察简报
- **数据可视化规范**:色盲安全配色(OKLab ΔE ≥ 8 已校验)、细线标记(2px)、置信区间带、十字光标悬浮、图例必备、数据表视图、状态色 + 图标双编码

## 📊 数据说明

数据为基于公开资料(**IPCC AR6 / NASA GISS / NOAA / IRENA / 国家能源局 / EM-DAT** 等)的**近似与推演数据**,仅供原型演示,不代表官方口径。核心锚点取自公开报告,中间年份由确定性插值生成;2026 年数值为全年预估。

## 🎤 演示脚本建议(5 分钟)

1. **30s 大屏开场**:全球大屏全屏模式 → 切换 4 项指标看地图"变色" → 1.5°C 警戒线仪表(距长期突破仅 1 年)
2. **90s 推演器**:滑块归零 → 达峰推迟/排放恶化 → 滑块拉高 → 实现碳中和 → 读 AI 建议
3. **60s 城市**:切孟买 vs 深圳,展开措施看实施路径(工程/自然基/数字三类)
4. **60s 预测中心**:1.5°C 突破、北极海冰、2100 海平面、作物减产
5. **60s AI 助手**:问"当前政策组合何时碳达峰?"展示数据联动 + 数据来源标注 → 切英文版展示国际化
